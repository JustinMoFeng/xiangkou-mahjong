# 巷口麻将牌型手册

本文档记录当前游戏已经实现的胡牌牌型、加分项和结算方式。当前项目使用简化倍率制，不使用传统番符、庄家连庄、本场、立直或役满包牌等规则。

## 胡牌牌型

| 牌型 | 成立条件 | 基础价值 |
| --- | --- | --- |
| 标准型 | 4 组面子 + 1 对将。面子可以是顺子、刻子或已副露的吃碰杠。 | 垃圾胡 1 倍 |
| 七对子 | 14 张牌组成 7 个对子；四张相同牌按两组对子计算。 | 垃圾胡 1 倍 + 门清 1 倍 + 七对子 2 倍 |
| 国士无双 | 1、9 万，1、9 筒，1、9 条，东南西北中发白各一张，且其中任意一种再成一对。 | 16 倍保底 |

## 额外加分项

| 加分项 | 成立条件 | 价值 |
| --- | --- | --- |
| 自摸 | 胡自己摸到的牌；结算时三家各付一份。 | +1 倍 |
| 门清 | 胡牌时没有任何吃、碰、明杠或补杠副露。 | +1 倍 |
| 碰碰胡 | 标准型的 4 组面子全部是刻子或杠子；明碰、明杠也计入。 | +2 倍 |
| 混一色 | 一种数字花色加任意字牌；和清一色不重复计算。 | +2 倍 |
| 清一色 | 全部牌都是同一种数字花色，且没有字牌；副露也计入。 | +2 倍，然后最终倍率 x2 |
| 杠 | 胡牌时持有的明杠、暗杠或补杠；暗杠不破门清。 | 每个 +2 倍 |
| 字牌刻子 | 每组东南西北中发白的刻子或杠子。 | 每组 +1 倍 |
| 花牌 | 春夏秋冬梅兰竹菊会自动亮出并补摸。 | 每张 +1 倍 |
| 杠上开花 | 明杠、暗杠或补杠后，补摸的牌胡牌。 | 最终倍率 x2 |
| 抢杠胡 | 别人补杠时，用那张补杠牌胡牌。 | +2 倍 |

## 结算方式

- 最终倍率 = 加法底分合计 x 所有翻倍项，最高 24 倍。
- 点炮胡：放铳者支付 `最终倍率 * 1000` 点，胡牌者获得同等点数。
- 自摸胡：三家各支付 `最终倍率 * 1000` 点，胡牌者共获得三倍点数。
- 任意一家点数小于或等于 0 时，整场结束。

## 杠牌

- 明杠：别人打出一张牌时，手里有三张相同牌可以杠。
- 暗杠：自己手里四张相同牌时可以暗杠；暗杠不破门清。
- 补杠：已经碰出三张牌后，自己摸到第四张相同牌，可以把碰升级为杠，并立即补摸一张牌。
- 杠分：胡牌时每个杠 +2 倍。
- 杠上开花：杠后补摸的牌胡牌，最终倍率 x2。
- 抢杠胡：别人补杠时，如果你能用那张补杠牌胡，可以抢杠胡，额外 +2 倍。

## 花牌

- 使用 8 张花牌：春、夏、秋、冬、梅、兰、竹、菊。
- 开局或摸牌时摸到花，会自动亮出并从牌山继续补摸。
- 花牌不进入手牌，不参与胡牌牌型判断。
- 每张花牌 +1 倍。
